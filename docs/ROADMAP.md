# Roadmap

What this proposal delivers, by phase. Budget and timeline detail is in
the funding submission.

| Phase | Deliverable |
|-------|-------------|
| 1 | Auditor role (independent database, scheduled consistency checks, alerting) |
| 2 | AML/KYC typed options over the `[kyc-rule-*]` mechanism |
| 3 | TLS/ACME termination for exchange + merchant endpoints |
| 4 | Automated encrypted backups (pg_dump, GPG, rclone) |
| 5 | Secrets management (sops/agenix integration) |
| 6 | Systemd hardening across all Taler services |
| 7 | Admin / merchant CLI |
| 8 | Integration tests: full stack (exchange + merchant + auditor) in NixOS VMs |
| 9 | nixpkgs PR — extension to the existing Taler module, coordinated with its maintainers |
| 10 | Documentation (EN + PT), demo deployment, final report |

This file is updated as the project progresses.
